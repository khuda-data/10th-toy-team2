전처리 파트에서 넘겨받은 k_slope / v_user를 교차검증으로 점검하고 재적합한 결과입니다.

## 1. 최종 산출물 — 어느 파일을 쓸 것인가

| 용도 | 파일 | 비고 |
|---|---|---|
| **k_slope (최종)** | `models/k_slope_model_v2.json` | 1차식, 정규화 적용 |
| **v_user (최종)** | `models/v_user_v2.csv` | 경사보정 방식 |
| 참고용 | `data/processed/segments_normalized.csv` | 원본 + speed_ratio 컬럼 |
| 구버전 (사용하지 말 것) | `data/processed/k_slope_model.json`, `v_user.csv` | 2절 사유로 대체 |

### ETA 계산식

```python
import json, numpy as np, pandas as pd

mj = json.load(open('models/k_slope_model_v2.json'))
v  = pd.read_csv('models/v_user_v2.csv').set_index('person')['v_user_mps']
lo, hi = mj['valid_slope_range']          # [-11.5, 11.6]

def k_slope(slope_pct):
    s = np.clip(slope_pct, lo, hi)        # 외삽 방지: 측정 범위 밖은 경계값
    return np.clip(np.polyval(mj['coef'], s), 0.3, 1.4)

speed = v[person] * k_slope(slope_pct)    # m/s
time  = dist_m / speed                    # 구간 소요시간(초)
```

경로 전체 ETA는 30~40m 구간별로 위 식을 적용해 합산하고, 신호대기(신호 파트 산출물)를
더하면 됩니다.

## 2. 왜 재적합했는가 — R² 대신 CV_R²

기존 모델은 in-sample R²로만 평가되어 있었습니다(가이드 3-1에 해당 사실 기재됨).
사람 단위 GroupKFold(6-fold) 교차검증을 처음 적용한 결과입니다.

| 종속변수 | 차수 | R² | **CV_R²** |
|---|---|---|---|
| `speed_mps` (기존 방식) | 1차 | 0.0359 | **−0.4778** |
| `speed_mps` (기존 방식) | 2차 | 0.0427 | **−0.4796** |
| `speed_ratio` (정규화) | **1차** | 0.0353 | **+0.0015** |
| `speed_ratio` (정규화) | 2차 | 0.0369 | −0.0131 |
| `speed_ratio` (정규화) | 3차 | 0.0370 | −0.0330 |

CV_R²가 음수라는 것은 "전체 평균값으로 예측하는 것보다 나쁘다"는 뜻입니다.

**원인.** `speed_mps`를 종속변수로 쓰면 회귀가 경사도가 아니라 참여자들의 절대 속도
수준을 학습합니다. 학습에 없던 사람에게 적용하면 무너집니다. 균형 표본(534개)은
한 사람 쏠림을 6명에게 분산시킬 뿐 이 문제 자체는 해결하지 못합니다.

**조치.** 종속변수를 각자의 평지속도로 나눈 `speed_ratio`로 변경.
개인 평지속도 = `|slope_pct| ≤ 1%` 구간의 `speed_mps` 평균(기존 정의 유지).

**차수.** CV_R²가 1차에서만 양수이므로 1차 채택. 2·3차는 과적합.
(기획안 "개선 없으면 단순선형 채택 — 2차항은 불필요했다도 결과입니다"에 해당)

**유지한 것.** 인원별 균형 표본(89개씩, 총 534개)은 그대로 사용합니다.
방향이 옳았고 쏠림 완화 효과가 있습니다.

## 4. 가이드 5절 "R² 0.082 → 0.019" 해석 수정

가이드 5절은 이 하락을 "데이터를 많이 모은 사람일수록 공통 곡선에서 벗어난다
= 개인화가 필요한 증거"로 해석했습니다. 사람별로 분해해 검증한 결과입니다.

### 학습(균형표본) 사람별 R²

| 권동하 | 윤예진 | 최희수 | 박준서 | 홍민기 | 김재형 |
|---|---|---|---|---|---|
| 0.2110 | 0.2054 | 0.1365 | 0.0074 | 0.0033 | −0.1439 |

### 확인된 사실 두 가지

1. 공통 곡선과 잘 맞지 않는 인원(홍민기 0.003, 김재형 −0.144)이 존재하는 것은 사실이나,
   이는 **미사용 데이터가 아니라 학습 표본 내부에서도 동일하게 관찰**됩니다.
   즉 "미사용 데이터라서 성능이 떨어진 것"이 아니라 원래 적합도가 낮은 인원입니다.
2. 이 편차는 **데이터 수집량과 비례하지 않습니다.** 중간 티어인 윤예진이 0.2054로
   상위권이고, 최소 표본인 김재형이 −0.1439로 최하위입니다.

또한 초과분 데이터는 윤예진·홍민기 두 명이 아니라 5명에게 흩어져 있으며
(권동하 8, 박준서 4, 윤예진 57, 최희수 1, 홍민기 365), 표본이 1~8개인 인원의 R²는
계산 자체가 무의미합니다. 하락분의 대부분은 홍민기 365개가 설명합니다.

### 보고서 기재 권장 문구

> 균형 표본으로 적합한 공통 곡선을 전체 데이터에 적용하면 R²가 0.082에서 0.019로
> 하락한다. 사람별로 분해하면 이 하락은 특정 인원(홍민기 0.003, 김재형 −0.144)이
> 공통 곡선과 잘 맞지 않는 데서 비롯되며, 학습 표본 내부에서도 동일하게 관찰된다.
> 다만 이 편차가 데이터 수집량과 비례하지 않아(윤예진 0.205로 상위), 개인의 경사 반응
> 차이인지 측정 환경 차이인지는 현 데이터로 구분하기 어렵다.
>
> 개인화 필요성의 독립적 근거로는 개인 평지속도 편차를 제시한다
> (SD = 0.126 m/s, 최대 25.7%).

## 5. 핵심 결론 — 발표 메시지

| 요인 | 크기 |
|---|---|
| **개인차** | 25.7% (최희수 1.627 ↔ 김재형 1.294) |
| **경사 효과** | +10% 경사에서 5.6% 감속 |

**개인차가 경사 효과의 약 4.5배입니다.**

> 지도앱이 놓치는 요인 중 경사도보다 개인차가 더 크다. 경사도 +10%가 만드는 속도 차이는
> 5.6%인 반면, 참여자 간 평지속도 차이는 최대 25.7%였다.

단, 다음 두 사실을 함께 기재해야 정직합니다.

- 경사 효과의 **존재와 방향은 통계적으로 확실**합니다(p = 8.9e-11). 969개 표본이라
  작은 효과도 유의하게 검출됩니다.
- 그러나 **크기가 작아 예측력은 거의 없습니다**(CV_R² ≈ 0.002). 측정 구간의 53%가
  −2~+2%에 집중되어 경사 축의 변동 폭이 좁았던 것이 주된 이유입니다.

이 둘은 모순이 아니라 "효과는 있으나 작다"는 하나의 사실입니다.

## 6. 남은 한계

- 급경사 내리막(≤ −8%)의 가속을 1차식이 포착하지 못함. 2차식은 CV에서 과적합.
- 측정 경사 범위가 −11.5~+11.6%이며 그 밖은 외삽. ETA 계산 시 경계값 클립 필수.
- 카테고리 명칭이 12종으로 분화되어 있고(가파른오르막/가파른오르막길 등),
  "가파른오르막"의 실제 평균 경사가 +4.0%로 "완만오르막"(+3.1%)과 유사함.
  회귀는 명칭이 아닌 `slope_pct` 연속값을 사용하므로 결과에는 영향 없음.
- 검증용 독립 경로 데이터 미수집 상태. 최종 성능(MAE/MAPE)은 그 데이터로 평가해야 함.

## 7. shrinkage 실험(가이드 3-2) 진행 시 참고

가이드 3-2의 3그룹 × 3방식 실험은 설계가 타당하나, 재적합 결과 v_user가 v_flat_raw와
근접하게 나왔으므로 (a)(b)(c) 세 방식의 차이가 예상보다 작을 수 있습니다.
실험 전 v_user와 v_flat_raw의 차이가 유의미한지 먼저 확인하시기 바랍니다.

## 재현 방법

```bash
python - <<'EOF'
import pandas as pd, numpy as np
from sklearn.linear_model import LinearRegression

d = pd.read_csv('data/processed/segments.csv')
flat = d[d.slope_pct.abs() <= 1].groupby('person')['speed_mps'].mean()
d['v_flat'] = d.person.map(flat); d = d[d.v_flat.notna()]
d['speed_ratio'] = d.speed_mps / d.v_flat

n = d.groupby('person').size().min()
bal = d.groupby('person', group_keys=False).apply(lambda g: g.sample(n, random_state=42))
m = LinearRegression().fit(bal[['slope_pct']], bal.speed_ratio)
print("기울기", m.coef_[0], "절편", m.intercept_)
EOF
```
